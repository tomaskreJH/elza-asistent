# Další kroky (po 0.33.0)
1. Založit seznamy Ukol, Smlouva, Technologie, Kontrola na webu Zakázky ELZA (docs/SEZNAMY-PLAN.md) a ostře ověřit Gantt a semafor; zapnout tok T12.
2. Portál: přihlášení z adres zákazníka, osoby ke zakázce, Schválení, Gantt milníků (PORTAL-ARCHITEKTURA bod 3 a 5).
3. Help desk z portálu → Případ (T13).
4. Semafor kontrol do Přehledu-velínu a do Můj den; závislosti úkolů (ZavisiNa) v Ganttu.
5. Čeká na Tomáše: příjemci T9, skutečný telefon, ZADOST-COPILOT, úklid testovacích dat, založení seznamů.
