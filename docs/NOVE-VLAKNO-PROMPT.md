ÚKOL 1 – VÝBĚR MODELU A TOKU (lepší / levnější), tak aby šlo měnit bez psaní textu:
Dnes jde model změnit jen tak, že se v AI nastavení napíše text (řádek v seznamu NastaveniAI: Agent, Nastroj, Model) a ten má přednost před vším ostatním (ai.js cfg(), pick(), modelPodle(), MDL/EF, DM), takže volba Úsilí a automatika nefungují. Udělej:
1. U každého Elzáčka a u ELZY volič místo volného textu: Nástroj (Claude předplatné / Claude API / Copilot / ChatGPT / Gemini / Lokální Ollama) a Model ze seznamu platných modelů pro daný nástroj + položka „Automaticky“. Volný text jen jako pokročilá položka „Vlastní model“ a vždy viditelně označená, že přebíjí automatiku.
2. Tři jednoduché předvolby u každého Elzáčka: Lepší (silnější model, vyšší Úsilí), Vyvážený, Levnější (nejlevnější model, který zvládne úlohu; lokální Ollama tam, kde stačí). Ke každé ukázat odhad tokenů a dopad na limity (z mostu /limity, pet.pct a tyden.pct).
3. Automatika podle limitů: při týdenním limitu nad 80 % (dnes 80 %) nebo 5hodinovém nad 80 % se doporučí levnější tok a ukáže se, co to změní; přepnutí vždy jedním klepnutím a vždy s návratem (docs/ZPET-ZASADA.md). Nic se nepřepíná potichu.
4. U řádku jasně ukázat, odkud se volba bere (výchozí kód / sdílená volba / osobní / vlastní text) a tlačítko „Zrušit vlastní text a vrátit automatiku“.
5. Měření: AI záznam (model, tokeny, režim, USD ekvivalent) nad volbami a přehled „co stálo nejvíc a čím to jde zlevnit“ (podklad pro hledání levnějších toků). Limity z mostu čti jen z jeho mezipaměti, nezvyšuj počet dotazů na Anthropic (429).
6. Ověř: test pro cfg() (priorita voleb), ukázkový režim, ostrý web ve vestavěném prohlížeči Claude (Tomáš je přihlášen firemním účtem, uložené přihlášení rovnou potvrdit), Test Elzáčka přes Claude (předplatné) s každou předvolbou; zapiš skutečné tokeny.
