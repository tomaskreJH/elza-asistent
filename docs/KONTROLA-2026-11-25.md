# Kontrola celé aplikace 2026-11-25 (0.73.9)
Zásada: bezpečnost, žádná upozornění Microsoft Defenderu, integrita firemního prostředí (viz docs/NOVE-VLAKNO-PROMPT.md).

## Nálezy podle závažnosti
**Vysoká (opraveno v 0.73.9)**
1. tools/elza-most.ps1 měl od 0.73.6 dvojitý BOM (EF BB BF EF BB BF). Windows PowerShell 5.1 přečte první jako kódování, druhý jako znak U+FEFF v kódu – pravděpodobná příčina, proč most po 0.73.6–0.73.8 nenaběhl. Uloženo s jedním BOM.
2. Instalátor stahoval a spouštěl skript z internetu (`irm https://claude.ai/install.ps1 | iex`) – klasický spouštěč Defenderu/AMSI. Odstraněno: chybí-li Claude CLI, instalátor jen ukáže oficiální návod.
3. Most kompiloval C# s DllImport kernel32 (Add-Type, vypnutí QuickEdit) – heuristika Defenderu, pro skryté okno zbytečné. Odstraněno.
4. Instalátor se spouštěl přímo ze složky, kde leží (často OneDrive). Nově .cmd zkopíruje skripty do %LOCALAPPDATA%\ElzaMost\instalace, odblokuje vlastní kopie a spustí odtud s -ExecutionPolicy RemoteSigned (dřív Bypass).
5. Pošta: Pošta ukládala režim zobrazení do atributu data-v na #mp; globální navigace (app.js) bere data-v jako cíl, takže po otevření vlákna každé klepnutí v čtecím panelu odvedlo na neexistující obrazovku „r“. Přejmenováno na data-mv.

**Střední (opraveno)**
6. ACL tokenu: icacls podle DOMÉNA\jméno selže u účtů Entra ID; nově podle SID aktuálního uživatele.

**Nízká / bez nálezu**
- SRI msal-browser.min.js: sha384 souboru = atribut integrity v index.html (hhkHFODse…). test/vzhled.py na 0.73.8 i 0.73.9 prochází; dřívější pád se nepotvrdil (pravděpodobně starý soubor v mezipaměti při tehdejším běhu).
- CSP index.html: script-src 'self', object-src none, base-uri self, form-action self; connect-src jen M365, Anthropic/OpenAI/Google API a 127.0.0.1:47321. Styly 'unsafe-inline' zůstávají (backlog).
- Pošta: HTML v iframe sandbox bez allow-scripts, vlastní CSP default-src none, vzdálené obrázky jen po klepnutí, odkazy do nového okna; přílohy stahováním. Odeslání jen přes confirmSend (zablokováno Strážcem, vyžaduje Mail.Send a potvrzení). ochrana.js filtruje vložené pokyny. elzy@ se nečte (CTI_SDILENOU=false v rano.js).
- Most: naslouchá jen 127.0.0.1, kontrola Host i Origin, token 32 B porovnávaný case-sensitive (bez tokenu 401), jediná persistence HKCU Run „ElzaMost“, mutex, žádné VBS, žádné výjimky Defenderu, ukončuje jen powershell.exe s přesnou cestou k instalovanému skriptu.
- Token mostu v aplikaci je v localStorage (jen origin aplikace, loopback) – přijatelné.
- integrity.json a stable/ sedí s kořenem (node tools/hash.js, tools/audit.js bez nálezů), všechny testy prochází.

## Čeká na rozhodnutí
- Limity Claude čtou přístupový token z %USERPROFILE%\.claude\.credentials.json (neoficiální zdroj). Funkčně OK, ale přístup ke credential souboru může EDR hodnotit jako „credential access“ s nízkou severity. Pokud to bezpečnost nechce, limity vypnout.
- --tools "" v lehkém režimu: předávání prázdného argumentu v PS 5.1 je křehké; dnes funguje (záloha úplného režimu).
